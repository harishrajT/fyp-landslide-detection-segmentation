# Ground-Level Landslide Instance Segmentation

This repository contains the source code, training scripts, and configurations for the research project: *"Automated Ground-Level Landslide Detection and Segmentation using Deep Learning"*.

## 📁 Repository Structure
- `data.yaml`: YOLO dataset configuration and class mappings.
- `train_yolo.ipynb`: Main training script for YOLO11s-seg hyperparameter optimization.
- `baselines/`: PyTorch training loops for U-Net, DeepLabV3+, and Mask R-CNN.
- `requirements.txt`: Python dependencies required to run the scripts.
